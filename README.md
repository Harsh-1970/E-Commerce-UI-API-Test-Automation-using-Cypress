# E-Commerce UI & API Test Automation

## 📌 Project Overview

This project is a **QA automation testing suite** developed using **Cypress and JavaScript** for testing an e-commerce web application.

The project focuses on automating important user workflows through **UI testing** and validating backend functionality through **REST API testing**.

The application used for testing is:

**Automation Exercise**  
https://automationexercise.com/

---

## 🎯 Project Objectives

The main objectives of this project are:

- Automate important e-commerce user workflows
- Perform functional UI testing using Cypress
- Perform REST API testing
- Validate positive and negative test scenarios
- Practice test case design and assertions
- Create reusable Cypress custom commands
- Validate API responses and status codes
- Practice debugging failed test cases
- Improve understanding of end-to-end test automation
